# 書籍構成案（第0版）

## この本の核

高校物理の公式を個別に暗記するのではなく、**現象を選んだ座標系で表し、ベクトルで整理し、変化を微積分で追う**という一つの見方を身につける。

各節は原則として、次の小さな往復で構成する。

1. 身近な現象・図・問いから始める。
2. 必要最小限の概念と式を導入する。
3. 1〜3問の「手を動かす問題」で直後に確認する。
4. 典型問題だけでなく、「なぜこの軸・この式を選ぶか」を言葉で振り返る。
5. 章末で、基礎・標準・探究の三段階の問題を置く。

## 1冊か、2冊か

初版は**1冊構成**とする。ただし、部ごとに独立して読める設計にし、将来は第I〜III部を「基礎編」、第IV〜VI部を「発展編」として分冊・再編集できるようにする。

理由は、力学で育てたベクトル・微積分・保存則の見方が、波動・電磁気・原子へ何度も戻ってくるためである。最初から2冊に固定すると、この共通言語が切れやすい。一方で、印刷版のページ数・対象学年・販売形態が固まった時点で分冊を判断する。

## 全6部の案

### 第I部　力学：運動をベクトルで読む

この本の入口。ベクトルを「矢印の計算」として終わらせず、位置・速度・加速度・力を記述する言葉として育てる。

1. 物理は何を記述するのか — 量、単位、モデル、グラフ
2. ベクトルの第一歩 — 加法、スカラー倍、成分、短い確認問題
3. ベクトルで現象を見る — 位置・変位・速度・加速度・力
4. 座標を選ぶ — 基準系と座標の区別、直交座標、成分分解
5. 運動を追う — 等加速度運動、位置‐速度‐加速度、微分・積分への入口
6. 力と運動方程式 — 自由体図、成分ごとの立式、拘束と摩擦
7. 仕事とエネルギー — 内積を「進行方向への寄与」として導入
8. 運動量と衝突 — 系を選ぶ、保存則を使う
9. 円運動と単振動 — 位置ベクトルの時間変化、微分による発展的導出

## 力学の導入順

```text
ベクトルの基本計算
  → 現象に現れるベクトル
  → 成分で測る（直交座標）
  → 座標・基準系を選ぶ
  → 運動方程式を成分ごとに解く
```

この順なら、斜方投射を「公式の適用」ではなく、位置・速度・加速度を成分に分けて再び合成する最初の成功体験にできる。

## 節の標準フォーマット

- **観察**：図または短い実験・日常例
- **考える**：予想を書く小問
- **道具箱**：定義・式・図
- **例題**：途中の判断を省略しない
- **手を動かす**：30秒〜3分程度の小問
- **振り返り**：何をベクトルで表し、なぜその座標を選んだか
- **発展**：微積分・3次元・より一般の座標系
