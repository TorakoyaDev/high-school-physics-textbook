# 書籍構成案（第0版）

## この本の核

高校物理の公式を個別に暗記するのではなく、**現象を選んだ座標系で表し、ベクトルで整理し、変化を微積分で追う**という一つの見方を身につける。

各節は原則として、次の順で構成する。

1. 対象となる物理量や概念を定義する。
2. 図や具体例によって意味を示す。
3. 数式と計算規則を導入する。
4. 数式が表す物理的意味を説明する。
5. 必要に応じて短い問題で確認する。

## 1冊か、2冊か

初版は**1冊構成**とする。ただし、部ごとに独立して読める設計にし、将来は第I〜III部を「基礎編」、第IV〜VI部を「発展編」として分冊・再編集できるようにする。

理由は、力学で育てたベクトル・微積分・保存則の見方が、波動・電磁気・原子へ何度も戻ってくるためである。最初から2冊に固定すると、この共通言語が切れやすい。一方で、印刷版のページ数・対象学年・販売形態が固まった時点で分冊を判断する。

## 全6部の案

### 第I部　力学：運動をベクトルで読む

この本の入口。ベクトルを「矢印の計算」として終わらせず、位置・速度・加速度・力を記述する言葉として育てる。

1. ベクトル — 大きさと向き、矢印、成分、加減算、スカラー倍、内積・外積
2. ベクトルの成分分解：1本の式を成分ごとに読む — 単位ベクトル、基底、成分の一意性、係数比較
3. 座標と運動の記述 — 基準系と座標系を区別し、位置・変位・速度・加速度をベクトルで表す
4. 直線運動と微積分 — グラフ、微分、積分から運動を読む
5. 平面運動 — 斜方投射と相対運動を成分に分けて扱う
6. 力と運動方程式 — 自由体図、成分ごとの立式、拘束と摩擦
7. 力のつり合いとモーメント — 剛体のつり合い、重心、外積を再訪
8. 仕事とエネルギー — 内積、積分としての仕事、位置エネルギー
9. 運動量と衝突 — 力積、保存則、重心運動、衝突
10. 円運動 — 速度・加速度の向きと向心加速度
11. 単振動 — 復元力と加速度から周期運動を導く
12. 万有引力 — 地上の運動と天体運動を同じ力学として捉える

## 力学の導入順

```text
ベクトルの表現と基本操作
  → 単位ベクトル、成分分解、係数比較
  → 座標・基準系を選ぶ
  → 運動方程式を成分ごとに解く
```

この順なら、斜方投射を「公式の適用」ではなく、位置・速度・加速度を成分に分けて再び合成する最初の成功体験にできる。

## 節の標準フォーマット

- **定義・対象**：扱う物理量や概念を明確にする
- **図・具体例**：定義の意味を想起できるようにする
- **計算・数式**：表記と計算規則を示す
- **物理的意味**：式と現象の対応を説明する
- **確認**：必要な箇所に短い問題を置く
- **発展**：微積分・3次元・より一般の座標系

## 合意済みの読者・数学方針

- 主な読者は、中学数学・理科を終えた高校物理の初学者とする。
- 高校数学のベクトルや数学IIIの微積分は前提にせず、必要な場面で本書内に導入する。
- 本文では図・変化量・具体例から意味を理解し、「微積で見る」欄で同じ内容を微分・積分から捉え直す。
- 微積分は単なる発展事項にはせず繰り返し使うが、未習者が最初の一周で欄を飛ばしても読み進められるようにする。
- 到達点は、高校物理の標準範囲を理解し、主要な公式をベクトルと微積分から説明できることである。
