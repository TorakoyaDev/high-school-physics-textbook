# 公開前レビュー・チェックリスト

## 内容

- [ ] 節の冒頭で「なぜ読むのか」が分かる。
- [ ] 新しい用語は、必要性が生まれた後に定義されている。
- [ ] 式の前後に、現象との対応を読む文章がある。
- [ ] 前提にしていない高校数学を説明なしで使っていない。
- [ ] 例と一般則の境界が明確である。
- [ ] 「成分に分けられる」と「物理的に独立である」を混同していない。
- [ ] 定義、数学的性質、物理法則、具体例が区別されている。
- [ ] 身近な説明のために、初期条件・摩擦・作用点など必要な条件を暗黙に変えていない。
- [ ] 章・節の主張が一文で言え、各例がその主張を支えている。
- [ ] ユーザー原稿がある場合、その内容・順序・語り口を不用意に置き換えていない。
- [ ] 複数の基本操作を扱う節では、各項目の説明形式が揃っている。
- [ ] 本文に編集方針や「この章の作り方」を説明するメタ文章が入り込んでいない。

## 文章

- [ ] 同じ語尾・文型が単調に続いていない。
- [ ] 表、箇条書き、calloutが本文を分断していない。
- [ ] 抽象語だけで説明せず、具体的な物体・動作・図に戻っている。
- [ ] 読者への問いが、直後に答えを明かすだけの飾りになっていない。
- [ ] 一段落の中心主張が一つに絞られている。

## 数式・図

- [ ] 表示数式が `$$ ... $$` で書かれている。
- [ ] `\[ ... \]` が残っていない。
- [ ] 数式がHTML上で文字列や角括弧に崩れていない。
- [ ] 図の本文、キャプション、altテキストが一致している。
- [ ] 色覚に依存せず、線種・ラベル・矢印でも区別できる。
- [ ] 単位が途中で落ちていない。

## 問題

- [ ] 新しい概念を直後の短問で使っている。
- [ ] 計算だけでなく、向き・符号・理由を問う問題がある。
- [ ] 解答に考え方が含まれる。

## 技術確認

- [ ] `quarto render --to html` が成功する。
- [ ] `rg -n '^\\\[|^\\\]$' --glob '*.qmd'` が0件である。
- [ ] 変更ページをブラウザで確認した。
- [ ] 章番号、目次、前後リンクが正しい。
- [ ] `git diff --check` が成功する。
