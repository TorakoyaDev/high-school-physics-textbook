# フィードバックから得た学び

ユーザーや試読者の指摘を、今後の章に再利用できる形で記録する。単なる修正一覧ではなく、原因・一般化した原則・反映先を残す。

> 2026-08-22以前の会話的・物語的文体に関する提案は履歴として残すが、現在の文体基準には使用しない。現在の基準はstyle-guide「本書の文体」に従う。

## 2026-08-22：表示数式が角括弧と一部の文字だけになった

- **観察**：三平方の定理の式が `[ =50, ]` と表示された。
- **原因**：Quarto原稿で表示数式に `\[ ... \]` を使用した。PandocのMarkdown処理でバックスラッシュがエスケープとして消え、数式として認識されなかった。
- **修正**：章内の表示数式を `$$ ... $$` へ統一する。
- **一般原則**：Quarto原稿では、インラインは `$ ... $`、表示数式は `$$ ... $$` のみを使う。
- **再発防止**：AGENTS.md、style-guide、review-checklistへ追加し、`rg` で禁止記法を検査する。

## 2026-08-22：文章が全体的に機械的に見える

- **観察**：定義、表、callout、短問が規則正しく並ぶ一方、読者が現象に引き込まれる流れが弱い。
- **原因**：教材要素を漏れなく配置することを優先し、場面・予想・驚き・概念導入の因果が薄くなった。文型と段落の長さも均一だった。
- **修正**：章冒頭を「二人が箱を引く場面」から語り直し、素朴な足し算では答えが決まらないことを読者自身が発見する構成にする。
- **一般原則**：章や節を読む動機には `場面 → 予想 → ずれ` の流れを活かす。ただし、概念や操作の説明では対象・定義・性質を明示し、場面を定義の代用にしない。表・枠は補助にとどめる。
- **反映先**：style-guide「本書の声」「説明の基本単位」、review-checklist「文章」。

## 2026-08-22：親しみやすさを優先し、学術的な骨格が見えなくなった

- **観察**：二人で箱を引く場面が章の中心になり、何を定義し、どの順に理解を積み上げる章なのかが見えにくくなった。
- **原因**：「現象から始める」という編集原則を強く適用しすぎ、ベクトルの基本操作を主軸、現象を意味付けの例とする役割分担を崩した。また、合力が物体の「動く向き」を決めるように読める表現があり、速度と加速度の区別に必要な条件を省略した。
- **修正**：章を `対象 → 定義 → 図形的意味 → 性質 → 物理的対応 → 確認` の階層で再設計する。加法・スカラー倍・内積・外積を章の柱とし、日常的な場面は各操作の後に置く。
- **一般原則**：親しみやすい例は定義の代用にしない。数学的操作と、それが物理現象に対応する根拠（定義または物理法則）を区別する。読みやすさのために物理的条件を落とさない。
- **反映先**：style-guide「本書の声」「説明の基本単位」、review-checklist「内容」、第2章設計書。

## 2026-08-22：ユーザー原稿を独自構成へ置き換えてしまった

- **観察**：ユーザーが提示した `基本操作 → 計算 → 物理的意味` という簡潔な原稿に対し、「理解の地図」や長い注意書き、独自の節構成を追加した。結果として原稿の主張と語り口が失われ、二度の全面的な不採用となった。
- **原因**：ユーザー原稿を第一資料ではなく、自由に再構成してよい参考メモとして扱った。また、「親しみやすい教材にする」という目的を、原稿の構造を変更する許可と誤認した。
- **修正**：第2章を全面的に書き直し、ユーザー原稿の `4つの基本操作と物理的意味 → 線形性と処理フロー → 基底と成分分解 → 具体例` を基本構成とする。既存本文は継ぎ足さない。
- **一般原則**：ユーザー原稿がある場合、それを内容・順序・語り口の第一資料とする。改善は正確性、表記、例題、読みやすさの補助に限定し、別構成への変更は事前に合意する。
- **反映先**：AGENTS.md、style-guide「基本操作を並べる節」、review-checklist「内容」、第2章設計書。

## 2026-08-22：文体を簡潔な学術説明文へ統一する

- **観察**：会話的に言い換えた文章よりも、ユーザー原稿の「物理学における多くの概念は〜として記述される」という簡潔な学術説明の方が、書籍本文として適切に見える。
- **決定**：本文は原則として「である」調とし、用語、数式、物理的意味を体系的に記述する。会話的・物語的な書き方は廃止する。
- **表記改善**：「概念」は文脈に応じて「物理量」へ正し、「同時に持つ」は「併せもつ」、「解き明かす」は「記述・解析する」とする。英語は初出時に `日本語（english）` の形で添える。
- **一般原則**：ユーザーが示した文章の論理と調子を保持し、改善は学術的な正確性と表記の統一に限定する。
- **反映先**：AGENTS.md、style-guide、review-checklist、第2章冒頭。
