# 編集・文章スタイルガイド

## 1. 本書の声

本書は、答えを知っている教師が結論を並べるのではなく、読者と同じ現象を眺めながら「何が不思議か」を一緒に見つける語り口を採る。ただし、親しみやすい場面は学術的な定義や論理を置き換えるものではない。各節で何を定義し、どこまで導き、何を例として示すのかを明確にする。

- 読者を急かさない。
- 幼く扱わない。
- 数学を権威として持ち出さず、現象を整理する必要から導入する。
- 驚きや手触りは具体的な状況から生み、過剰な煽り文句は使わない。
- 日常語による説明のために、物理的な条件や因果関係を変えない。
- 例は概念を説明するが、概念の定義そのものにはしない。

## 2. 説明の基本単位

一つの概念は、原則として次の流れで説明する。

1. **場面**：目に浮かぶ現象を一つ置く。
2. **予想**：読者が計算前に答えを考えられる問いを置く。
3. **ずれ**：素朴な足し算や既知の考えでは説明しきれない点を示す。
4. **道具**：その不足を埋める概念・表記・式を導入する。
5. **読む**：式を日本語で読み、各項が現象の何を表すか説明する。
6. **試す**：短い問題で、自分の手で同じ見方を使う。
7. **戻る**：最初の場面を新しい言葉で説明し直す。

毎節をこの型へ機械的に押し込める必要はないが、「定義 → 式 → 練習」のみで終わらせない。

概念や計算操作そのものが主題となる節では、次の学術的な骨格を優先する。

1. **対象**：何を扱うか、どの量に適用できるか。
2. **定義**：操作や用語を曖昧さなく定める。
3. **図形的・数学的意味**：式や図が何をしているかを説明する。
4. **性質**：交換法則など、後で使う性質を示す。
5. **物理的対応**：定義と現象を混同せず、どの法則や定義によって結び付くかを示す。
6. **確認**：単純な状況で操作と解釈を確かめる。

導入の場面はこの骨格へ入る動機を作るために使い、節全体の論理を場面任せにしない。

### 基本操作を並べる節

複数の数学的操作を体系的に説明する節では、操作ごとに次の形式を揃える。

1. **操作名**
2. **計算**：式と計算規則を簡潔に示す。
3. **物理的意味**：現象の中で何を表す操作かを一言で示す。
4. **具体例**：中学数学または日常的に想像できる現象で式を読む。
5. **短問**：同じ判断を一度だけ自力で使う。

この形式では、読者を引き込むための物語や、章の設計意図を説明する文章を挟みすぎない。簡潔な反復によって操作どうしを比較できることを優先する。

## 3. 自然な日本語

- 一段落には中心となる主張を一つ置く。
- 同じ文型や「〜です」を3文以上続けない。
- 抽象語を重ねず、可能なら物体・動作・向きを主語にする。
- 「〜することができます」は、多くの場合「〜できます」または能動文にする。
- 「このように」「つまり」「したがって」を、論理関係がない場所の接着剤として使わない。
- 見出し直後に、その節を読む動機が分かる一文を置く。
- 用語を太字にするだけで説明したことにしない。

## 4. 表・箇条書き・callout

- 比較軸が揃う情報は表にする。物語や因果関係は本文で書く。
- 箇条書きは並列な項目に使い、説明の主役にしない。
- calloutは「問い」「重要な注意」「例題」など、本文から視覚的に分ける価値がある場合だけ使う。
- calloutを二つ以上連続させない。
- 一画面が枠と表ばかりにならないよう、本文と図に呼吸を作る。

## 5. 数式

- インライン数式：`$ ... $`
- 表示数式：`$$ ... $$`
- Markdown内では `\[ ... \]` を使わない。
- 式を置く前に「何を求める式か」、置いた後に「何が読み取れるか」を書く。
- 等号変形が教育上重要なら途中式を省かない。自明なら式を増やさない。
- 物理量と単位を混同しない。数値例では単位を最後まで付ける。

## 6. 問題と解答

- 計算前に向き・符号・大小を予想させる問題を含める。
- 一つの短問で新しい判断を一つだけ問う。
- 解答は数値だけでなく、判断の根拠を一文添える。
- 読者が誤りやすい答えには、なぜそう考えやすいかも説明する。

## 7. 初稿の推敲

初稿を書いた後、次を削る・直す。

- 学習目標を言い換えただけの段落
- 直前の式を同じ言葉で繰り返す段落
- 読者がまだ必要性を感じていない定義
- 内容を前へ進めない接続語
- 不要な括弧書き
- 表やcalloutへ移した方が読みやすい補助情報
