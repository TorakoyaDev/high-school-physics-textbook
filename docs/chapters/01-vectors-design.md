# 第1章「ベクトル――大きさと向きを表す方法」設計記録

## 正本

本文の正本は `docs/reference/ch01-final-source.md` である。「物理教科書原稿を壁打ち」タスクにおける最後の全体稿を、未編集で保存したものである。

公開用 `mechanics/vectors.qmd` では、次の変換だけを行う。

1. 原稿先頭の章見出しをQuartoのYAMLタイトルへ移す。
2. 自動採番を無効にし、確定稿の節番号をそのまま表示する。
3. 数式区切り `\(...\)` / `\[...\]` を `$...$` / `$$...$$` に変換する。

上記以外の文章、見出し、順序、数式内容は変更しない。

## 次章への接続

第1章では、分解と再合成の体系的な説明を行わない。第2章で、1本のベクトルを方向ごとの成分へ分解し、成分ごとに計算した後で再合成する方法と、その背景にある線形性を扱う。
