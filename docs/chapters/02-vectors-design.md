# 第2章「ベクトル」設計書

## 章の役割

本書全体で使う「向きのある量の読み書き」を身につける章とする。章の主軸は、ベクトルに対する四つの基本操作――加法、スカラー倍、内積、外積――である。身近な現象は操作を導入する代用品ではなく、その数学的意味が物理でどのように現れるかを確かめる例として用いる。

理解は次の階層で構築する。

1. **対象**：スカラーとベクトルを区別し、矢印で表す。
2. **基本操作**：加法、スカラー倍、内積、外積を定義する。
3. **数学的意味**：つなぐ、伸縮・反転する、射影する、垂直方向を作る操作として読む。
4. **物理的意味**：変位、合力、運動方程式、仕事、力のモーメントとの対応を知る。
5. **測定と計算**：座標軸と基底を選び、成分として計算する。
6. **現象の処理**：ベクトルを分解し、式を立て、結果を再統合する。

数学的に操作できることと、その操作が特定の物理現象を表すことは別の主張として扱う。たとえば、二つの力の合力をベクトル和で定義すること、運動方程式が合力と加速度を結ぶこと、速度が運動の向きを表すことを混同しない。

この章は本書の試作章でもある。説明、図、短い問題、「微積で見る」欄の基本レイアウトをここで検証し、後続章のテンプレートにする。

## 前提知識

- 正負の数と四則演算
- 比例
- 直角三角形と三平方の定理
- 三角比は章内で必要なところを復習する

高校数学でのベクトル既習を前提にしない。

## 章末の到達目標

読者が次のことをできる状態を目指す。

1. スカラーとベクトルを、単なる「数字と矢印」ではなく物理量の性質として区別できる。
2. ベクトルの加減算とスカラー倍を、図と成分の両方で計算できる。
3. 位置、変位、速度、加速度、力がどのようなベクトルか説明できる。
4. 一つのベクトルを選んだ座標軸の成分として表し、再び合成できる。
5. 同じベクトルでも座標軸を変えると成分が変わることを説明できる。
6. 内積を「一方の向きへの寄与」、外積を「回転させる効果」として説明できる。
7. 問題に応じて、図・大きさと向き・成分表示のどれを使うか選べる。

## 章を貫く問い

> 向きのある量を、どうすれば計算できる形で測り、組み合わせられるだろうか。

## 節構成

### 2.0 導入：この章で作る理解の地図

位置、速度、加速度、力などに共通する「大きさと向き」を計算する必要を短く示す。加法、スカラー倍、内積、外積がそれぞれ何をする操作かを見取り図として提示する。二人で荷物を引く場面は加法の節へ移し、章全体を一つの例に従属させない。

### 2.1 大きさだけの量、向きも必要な量

- スカラー：質量、時間、温度、エネルギー
- ベクトル：変位、速度、加速度、力
- 「正負」と「向き」は同じではなく、正方向を決めて初めて符号が意味をもつ
- 単位を含めて物理量を表す

**手を動かす**：量をスカラーとベクトルに分類し、判断理由を一言で書く。

### 2.2 ベクトルを矢印で表す

- 矢印の長さと向き
- 始点を移しても大きさと向きが同じなら同じ自由ベクトルとして扱う
- ベクトルの大きさ $|\boldsymbol{A}|$
- 等しいベクトル、逆ベクトル、零ベクトル

**誤解への対応**：「矢印の置かれた場所」そのものが常にベクトルの一部とは限らない。位置ベクトルとの違いは第3章で深める。

### 2.3 基本操作1――加法：二つのベクトルを一つにまとめる

- 同じ種類・同じ次元の物理量を加えることを確認する
- 三角形則と平行四辺形則
- 結合法則と交換法則
- 変位の合成は「移動を順につなぐ」という定義、合力は「同時に働く力をまとめる」という定義として区別する
- 二人が箱を引く例は、加法を定義した後の計算例にする
- 合力が直接決めるのは加速度であり、速度や移動方向ではないことを予告する

**手を動かす**：方眼上の経路、同一直線上の力、直角方向の力を順に扱う。

### 2.4 加法から生まれる操作――逆ベクトルと減法

- 逆ベクトル
- 零ベクトル
- 引き算を逆ベクトルの足し算として定義する
- 位置・速度などの変化量を「後 − 前」で表す

### 2.5 基本操作2――スカラー倍：大きさを変え、向きを反転する

- 正の倍率、負の倍率、ゼロ倍
- 大きさ1の単位ベクトル
- $\boldsymbol{F}=m\boldsymbol{a}$ はスカラー倍の形をもつ物理法則として予告する
- 数学的なスカラー倍の定義と、力・質量・加速度の因果関係を同一視しない

**手を動かす**：図示、倍率の決定、向きの反転を短問で確認する。

### 2.6 物理現象をベクトルで整理する

- 位置と変位
- 平均速度と加速度は「変化量」から生まれるベクトル
- 合力と重ね合わせ
- 現象を「対象を選ぶ → ベクトルを描く → 組み合わせる」の順で整理する

ここでは運動公式や運動方程式を解かず、第3章・第6章への橋を架ける。

### 2.7 座標でベクトルを測る

- 原点、軸、正方向を選ぶ
- 直交する単位ベクトル $\boldsymbol{i},\boldsymbol{j}$
- $\boldsymbol{A}=A_x\boldsymbol{i}+A_y\boldsymbol{j}$
- 図から成分を読み、成分から矢印を復元する
- $|\boldsymbol{A}|=\sqrt{A_x^2+A_y^2}$
- 三角比による $A_x=A\cos\theta$, $A_y=A\sin\theta$

**重要な主張**：成分はベクトルそのものではなく、選んだ軸に沿って測った値である。

### 2.8 成分で計算する

- 加減算とスカラー倍を成分ごとに行う
- 基底ベクトルが線形独立であることを、矢印と係数比較から直感的に説明する
- ベクトル方程式を成分の式へ分けられることを示す

**注意**：成分ごとに式を書けることと、現象の各方向が常に物理的に独立であることを混同しない。

### 2.9 基本操作3――内積：ある向きへの寄与を取り出す

- 射影としての $\boldsymbol{A}\cdot\boldsymbol{B}=AB\cos\theta$
- 成分表示 $A_xB_x+A_yB_y$
- 結果がスカラーになる意味
- 垂直なら内積が0になる
- 仕事 $W=\boldsymbol{F}\cdot\boldsymbol{x}$ を第8章の予告として扱う

**手を動かす**：同方向、逆方向、直角、斜めの順で符号と大きさを予想してから計算する。

### 2.10 基本操作4――外積：垂直方向と回転の向きを表す

- 大きさ $|\boldsymbol{A}\times\boldsymbol{B}|=AB\sin\theta$
- 向きは二つのベクトルに垂直で、右ねじの規則で決める
- 順序を逆にすると向きが反転する
- 力のモーメント $\boldsymbol{\tau}=\boldsymbol{r}\times\boldsymbol{F}$
- ドアを押す位置と向きを具体例にする

初回は意味と図を優先する。3次元の行列式による成分計算は本文の必須事項にせず、発展欄へ置く。

### 2.11 ベクトルによる現象の処理

- 対象を選ぶ
- 座標軸と基底を選ぶ
- ベクトルを成分へ分解する
- 成分ごとの式を立てる
- 結果をベクトルとして再統合する
- 斜方投射を、後続章で完成させる処理例として見通す

### 2.12 まとめ：操作と表し方を選ぶ

同じ問題を、矢印、成分、内積・外積のいずれで扱うと見通しがよいか比較する。

- つなぐ・重ねる：加減算
- 伸ばす・反転する：スカラー倍
- ある向きへの寄与：内積
- 回転させる寄与：外積
- 数値として計算する：成分表示

## 必要な図

1. 二人がロープで荷物を引く導入図
2. 同じ向き・反対向き・直角のベクトル加法
3. 三角形則と平行四辺形則
4. ベクトルの成分分解と再合成
5. 軸を回したとき、矢印は同じで成分だけが変わる比較図
6. 射影としての内積
7. ドアと力のモーメント
8. 右ねじの規則を示す外積の立体図

図は色だけに意味を持たせず、線種・矢印・ラベルでも区別できるようにする。
