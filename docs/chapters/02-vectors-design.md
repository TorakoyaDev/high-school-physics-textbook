# 第2章「ベクトル」設計書

## 章の役割

位置、速度、加速度、力などを共通の方法で扱うために、ベクトルの基本操作とその物理的意味を学ぶ章とする。

ユーザー原稿「物理学におけるベクトルの基本操作と現象の処理」を第一資料とし、次の順序を基本とする。

1. ベクトルの基本計算とその物理的意味
2. ベクトルの線形性と物理現象の処理フロー
3. 基底ベクトルと成分分解の論理的根拠
4. 斜方投射による分解・計算・再統合の具体例
5. 座標系によるベクトルの測り方
6. ベクトルと微分による円運動の見通し

原稿の簡潔な説明形式を保ち、初学者向けの補助として図、日常的な例、短い問題を加える。章の構成意図を本文で長く説明しない。

## 前提知識

- 正負の数と四則演算
- 比例
- 直角三角形と三平方の定理
- 三角比は必要な箇所で復習する

高校数学でのベクトル既習、数学IIIの微積分は前提にしない。

## 章末の到達目標

1. スカラーとベクトルを区別できる。
2. 加法、スカラー倍、内積、外積について、計算方法と物理的意味を説明できる。
3. ベクトルを直交座標の成分で表し、加法とスカラー倍を成分ごとに計算できる。
4. 基底の線形独立性から、ベクトル方程式を成分の式へ分けられる理由を説明できる。
5. 現象を成分へ分解し、各成分で計算し、ベクトルとして再統合できる。
6. 座標軸の選び方によって成分は変わるが、ベクトルそのものは変わらないと説明できる。

## 節構成

### 2.1 ベクトルの基本計算とその物理的意味

物理学で多用される四つの基本操作を、同じ説明形式で並べる。

#### ① ベクトルの加法

- **計算**：対応する成分を足す。
- **物理的意味**：効果の重ね合わせ。
- **主な例**：合力、変位、電場・磁場の重ね合わせ。
- **短問**：同方向、反対方向、直角方向の力。

#### ② スカラー倍

- **計算**：各成分を同じ実数倍にする。
- **物理的意味**：ベクトル量の比例関係。
- **主な例**：$\boldsymbol{F}=m\boldsymbol{a}$。
- **短問**：正、負、0による向きと大きさの変化。

#### ③ 内積

- **計算**：成分の積の和、または $AB\cos\phi$。
- **物理的意味**：ある方向への寄与を取り出す。
- **主な例**：仕事 $W=\boldsymbol{F}\cdot\boldsymbol{x}$。
- **短問**：同方向、反対方向、直角方向での符号。

#### ④ 外積

- **計算**：大きさ $AB\sin\phi$、向きは二つのベクトルに垂直。
- **物理的意味**：回転の軸と向き、垂直な効果。
- **主な例**：力のモーメント、ローレンツ力。
- **短問**：ドアを押す位置と向きによる回しやすさ。

外積の行列式計算は必須事項にせず、現象の理解を優先する。

### 2.2 線形性と物理現象の処理フロー

- 加法とスカラー倍の分配法則・結合法則
- 複雑なベクトルを成分へ分解してよいこと
- `成分分解 → 各成分で立式・計算 → ベクトルとして再統合` の三段階
- 線形なベクトル計算と、物理法則そのものが線形であることを混同しない

### 2.3 基底ベクトルと成分分解の論理的根拠

- $\boldsymbol{A}=A_x\boldsymbol{i}+A_y\boldsymbol{j}$
- 基底ベクトル $\boldsymbol{i},\boldsymbol{j}$
- 線形独立
- 係数比較
- $\boldsymbol{F}=m\boldsymbol{a}$ を $F_x=ma_x$, $F_y=ma_y$ へ分ける
- 式を成分ごとに書けることと、現象が常に物理的に独立であることを区別する

### 2.4 具体例：斜方投射

- 初速度と重力加速度の成分分解
- $x$ 成分と $y$ 成分での計算
- 位置ベクトルへの再統合
- 詳細な運動公式は後続章で学ぶことを明記する

### 2.5 座標系によるベクトルの測り方

- ベクトルそのものと成分の区別
- 直交座標と極座標
- 座標軸を変えると成分が変わる
- 基準系（誰が見るか）と座標（どう測るか）の区別は見通しのみ示し、第3章以降で詳述する

### 2.6 発展：ベクトルと微分による円運動

- $\boldsymbol{r}(t)=(r\cos\omega t,r\sin\omega t)$
- $\boldsymbol{v}=d\boldsymbol{r}/dt$
- $\boldsymbol{a}=-\omega^2\boldsymbol{r}$
- 微分未習者向けの幾何学的説明と併記する

## 説明形式

基本操作は、必ず次の形式を揃える。

1. 操作名
2. 計算
3. 物理的意味
4. 具体例
5. 手を動かす短問

本文は簡潔な説明文を基本とする。物語的な導入、長い注意書き、編集方針の説明を基本操作の間に挟まない。
